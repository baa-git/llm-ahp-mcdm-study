# Data provenance

## Supplier performance data

- Source: "Procurement KPI Analysis Dataset", published on Kaggle by Shahriar Kabir,
  https://www.kaggle.com/datasets/shahriarkabir/procurement-kpi-analysis-dataset
  (page accessed 3 November 2026 according to the project notes; download date and dataset version were
  not recorded).
- The CSV itself is **not** included in this repository. The working copy had 777 purchase-order rows
  for five suppliers (Alpha_Inc 141, Beta_Supplies 156, Delta_Logistics 171, Epsilon_Group 166,
  Gamma_Co 143); these counts equal the row sums of the four order-status columns D1-D4 of the
  performance matrix.
- Derived file: `data/performance_matrix.json` (5 suppliers x 8 indicators: delivered, pending, cancelled
  and partially delivered order counts; average discount rate; defective rate; average items per order;
  non-compliance rate), copied verbatim into the `ranking` block of `problems/supplier_selection.json`.
  The analysis converts the four counts into percentages of each supplier's order total.
- The guided prompts (`prompts/guided/`) embed a data-analysis report (in Turkish) computed from the same
  dataset; they are the original thesis prompts and are used only in the guided condition.
- The license of the Kaggle dataset has not been verified (see "Open points").

## Expert matrices

- `data/expert_matrices.json`: pairwise-comparison matrices of seven experts for the five main criteria
  and the four delivery sub-criteria (Saaty scale, reciprocal), from the answers to the questions the experts were asked.
- Experts are labelled E1-E7 in file order. The file contains only the numeric matrices and the criterion
  names: no names, affiliations, contact details, demographics or other personal data.

## Prompts and problem files

- `prompts/PROMPT_TASLAK.md`: the unguided (key `lean`), CoT (key `cot`) and revision prompt drafts written
  for this study, a historical working document in which the unguided condition is still called LEAN (the
  code builds the prompts; the audit checks that stored messages
  equal the code's output).
- `prompts/guided/`: the original guided prompt files, byte-identical to the copies shipped with the code
  (`problems/guided/` in https://github.com/baa-git/llm-ahp-mcdm); the audit compares them with every stored
  guided message.
- `problems/supplier_selection.json`: the study's problem definition (criteria, question order, ranking
  block), a copy of the file shipped with the code.
- `models.json`: the model panel and judge settings used in the study, a copy of the code's default panel.
